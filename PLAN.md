# PLAN.md – Glæde og Vækst Pasning

## Mål
Færdig single-file hjemmeside klar til at uploade/hoste.

---

## Fase 1 – Struktur og indhold
- [ ] Opret `index.html` med alle sektioner som tomme HTML-skelet
- [ ] Indsæt alt tekstindhold (fra briefing) i korrekte sektioner
- [ ] Tilføj semantiske HTML-tags (header, main, section, footer, nav)
- [ ] Placeholder-kommentarer hvor Elham skal indsætte egne billeder

## Fase 2 – Design og styling
- [ ] CSS custom properties (farver, fonte, spacing)
- [ ] Google Fonts integration (vælg passende fontkombination)
- [ ] Hero-sektion med visuel vægt og "Ledige pladser"-badge
- [ ] Anbefalings-sektion (cards eller citater med grafisk accent)
- [ ] Billedgalleri eller grid i hverdags-sektionen (18 billeder fra `img/`)
- [ ] Lightbox eller simpel scroll-galleri til billederne
- [ ] Evt. hero-baggrundsbillede (vælg det mest indbydende)
- [ ] Subtile animationer ved scroll (fade-in)

## Fase 3 – Interaktivitet og detaljer
- [ ] Smooth scroll navigation
- [ ] Mobil hamburger-menu (hvis navigation bruges)
- [ ] Kontaktknapper (tel: og mailto: links)
- [ ] "Ledige pladser" tydelig call-to-action
- [ ] Favicon (simpel bogstav-favicon)

## Fase 4 – Kvalitetssikring
- [ ] Test på mobil (320px–430px)
- [ ] Test på tablet og desktop
- [ ] Tjek alle links virker
- [ ] Validér HTML
- [ ] Gennemgå tilgængelighed (kontrast, alt-tekster, tabindex)

## Fase 5 – Levering
- [ ] Minify CSS/JS hvis ønsket
- [ ] Instrukser til Elham om at indsætte egne billeder
- [ ] Upload-vejledning (GitHub Pages, Netlify eller simpel hosting)
