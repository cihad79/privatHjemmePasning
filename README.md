# Glæde og Vækst Pasning

Hjemmeside for Elham – privat pasningsordning i Bispebjerg, København.

## Om projektet

En statisk single-page hjemmeside bygget med ren HTML, CSS og JavaScript (ingen frameworks). Siden præsenterer Elhams tilbud til forældre med børn i alderen 0–3 år.

## Struktur

```
privatHjemmePasning/
├── index.html              # Forsiden (single-page)
├── favicon.ico
├── robots.txt
├── sitemap.xml
├── site.webmanifest
├── pages/
│   ├── cookiepolitik.html
│   └── privatlivspolitik.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── img/                # Aktivitetsbilleder + logo
    └── favicons/           # Favicon-varianter
```

## Tech stack

- Vanilla HTML / CSS / JavaScript
- Google Fonts (Lora + Inter)
- Lucide ikoner via CDN
- Ingen build-tools eller afhængigheder
